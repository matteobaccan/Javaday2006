# Javaday 2006 — Tiger, Mustang e Dolphin

Le mie slide presentate al **Javaday di Roma** il **2 dicembre 2006**:

> **"Tiger, Mustang e Dolphin: le nuove caratteristiche di JAVA 5, 6 ... 7(?)"**

50 minuti per svelare la tigre, il cavallo e sapere che esiste il delfino.

## L'intervento

- **Relatore**: Matteo Baccan — JUG Novara
- **Evento**: Javaday Roma, 2 dicembre 2006, ore 10:00
- **Area**: Programming & development
- **Target**: Tecnici — Difficoltà: Media

La presentazione illustra le caratteristiche introdotte con Java 5 (Tiger), da tempo attese nello standard del linguaggio, con uno sguardo a Java 6 (Mustang) e a quello che sarebbe diventato Java 7 (Dolphin).

## Argomenti trattati

**Java 5 — Tiger**
- Metadata (Annotations)
- Generic Types
- AutoBoxing e Unboxing dei tipi primitivi
- Static import
- Enhanced for loop e gestione dinamica delle Enumeration

**Java 6 — Mustang**
- Gestione della SystemTray
- Motori di scripting
